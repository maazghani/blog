# Maaz's Blog

My personal blog, built with [Astro](https://astro.build). It features a collection of articles on topics I am passionate about, along with a showcase of my projects.

The site uses [Pagefind](https://pagefind.app) for search, includes a sitemap and RSS feed, and supports Markdown + MDX. Styled with TailwindCSS and supports system, light, and dark themes.
